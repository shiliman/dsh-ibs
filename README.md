# dsh-ibs · 肠易激

DSH 的一条「肠易激」副线：肠子一阵一阵地绞，坐着不如站着；到线后对话中途必须先离席一趟。
默认**不开**（`defaultEnabled: false`），要在这个会话里说得上这回事，用工具 `ibs_on` / `ibs_worse` / `ibs_relief`。

## 它到底做什么

- 每个会话一份身体状态，存在 `$DSH_HOME/dsh-ibs/sessions/<sid>.json`
- 每轮按配置算时长（默认 12 分钟一轮）攒「难受值」
- 到 `startAt`（默认 34）开始有可感知的注入；到 `flareAt`（默认 76）有 `flareChance` 的概率发作
- 注入只写**感受与说话要求**，不写解剖细节；平静时一个字都不注入
- 同一个状态有冷却（默认 8 分钟），发作 / 刚处理完不受冷却限制

## 语言方式（和其他插件不一样的地方）

演**离席**：允许「你等我两分钟」，回来后接着原话题，不重新解释；明确不许描述排泄、不许拿这个开玩笑。

## 工具

| 工具 | 用途 |
|---|---|
| `ibs_on` / `ibs_off` | 开关这个会话的副线 |
| `ibs_status` | 读当前会话状态 |
| `ibs_relief` | 处理一下：去一趟 / 热水袋焐着 / 吃一片药 |
| `ibs_worse` | 主动加重（默认一轮的量） |

## 配置要点

| 键 | 默认 | 说明 |
|---|---|---|
| `enabled` | true | 总闸 |
| `defaultEnabled` | false | 新会话默认开不开 |
| `eeriness` | 2 | 语气不对劲的上限 0–3 |
| `gain` | 0.36 | 每轮加重 |
| `flareChance` | 0.38 | 到线后每轮发作概率 |
| `startAt` / `flareAt` | 34 / 76 | 有感觉 / 快发作 |

## 面板

侧边栏会多一格「肠易激」，点开是一块面板页：

- 此刻的难受度（肠易激）、刻着 `startAt` / `flareAt` 的刻度条、烦躁 / 发作次数 / 参与轮次 / 上次注入
- 最近这一路的曲线（实线难受度、虚线烦躁，最多 180 个点，面板开着每 15 秒记一个）
- 动手：开关这条副线、按 5 / 12 / 30 分钟加重、按缓解方式处理一下、把状态清回一开始
- 这个病怎么表现（平静 / 隐痛 / 发作三档原文）与它自己的语言方式

肚子绞一下就得离席两分钟，回来接原来的话题。
面板读的是引擎自己落的 `sessions/*.json`，改状态走同一份运行时缓存，不绕过引擎。没有 `webServer`（纯 CLI）时面板不存在，插件照常工作。

## 卸载

从 profile 的 bundles 里移除 `dsh-ibs`，再删 `$DSH_HOME/dsh-ibs`。

> 只产出源码，本机未安装。
